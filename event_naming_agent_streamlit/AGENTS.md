# Правила проекта

- Не отправлять данные никуда, кроме настроенного OpenRouter API.
- Не добавлять в исходный код ключи, токены и реальные банковские данные.
- Использовать только синтетические или обезличенные учебные файлы.
- Не подключать Jira, Figma, почту, мессенджеры и банковские системы.
- Не вставлять контрольные примеры в системный промпт модели.
- Не считать автоматическую проверку `OK` согласованием аналитика.
- Любой XLSX является черновиком до ручной проверки.
