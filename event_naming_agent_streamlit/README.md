# Агент нейминга продуктовых событий

Учебный Streamlit-прототип по спецификации команды. Приложение принимает бизнес-требования, регламент и каталог событий, задаёт уточняющие вопросы, создаёт черновую разметку через OpenRouter и формирует XLSX с листами `Events` и `Риски`.

## Что реализовано

- обязательная загрузка БТ в PDF/DOCX, регламента в PDF/DOCX/TXT и каталога в XLSX/CSV;
- локальная проверка файлов до обращения к модели;
- обнаружение упоминаний чувствительных полей;
- предварительный этап уточняющих вопросов;
- генерация строго структурированного JSON;
- проверка Event name, Action, dimensions, дублей и запрещённых полей;
- предпросмотр результата;
- XLSX с подсветкой строк, требующих согласования;
- понятные сообщения об ошибках и лимите OpenRouter;
- отсутствие интеграций с Jira, Figma, почтой и системами банка.

## Локальный запуск

Требуется Python 3.11+.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .streamlit/secrets.toml.example .streamlit/secrets.toml
streamlit run app.py
```

В `.streamlit/secrets.toml` укажите:

```toml
OPENROUTER_API_KEY = "ваш ключ"
OPENROUTER_MODEL = "openrouter/free"
```

Файл с секретами исключён из Git. Не отправляйте ключ в чат и не добавляйте его в репозиторий.

## Развёртывание в Streamlit Community Cloud

1. Создайте GitHub-репозиторий и загрузите туда проект без `.streamlit/secrets.toml`.
2. В Streamlit Community Cloud выберите `Create app` и укажите `app.py`.
3. В Advanced settings → Secrets добавьте `OPENROUTER_API_KEY` и `OPENROUTER_MODEL`.
4. Разверните приложение и проверьте ссылку с другого устройства.

## Важные ограничения

- Используются только синтетические или обезличенные учебные данные.
- Бесплатные модели и квоты OpenRouter могут меняться и быть временно недоступны.
- `openrouter/free` выбирает доступную бесплатную модель. Перед защитой рекомендуется зафиксировать конкретную протестированную модель с суффиксом `:free`.
- Изображения из DOCX извлекаются и отображаются в диагностике, но текущий запрос к модели использует текст. Если скриншот содержит критически важную информацию, добавьте её текстовое описание в БТ. Поддержку конкретной мультимодальной модели нужно протестировать отдельно.
- Если фактический корпоративный XLSX-шаблон не совпадает со встроенными заголовками, приложение создаёт безопасный стандартный файл. Перед защитой следует приложить реальный пустой шаблон и зафиксировать его колонки.
- Результат всегда является черновиком. `OK` означает прохождение автоматических проверок, но не согласование системным аналитиком.
